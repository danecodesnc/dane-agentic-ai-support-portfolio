/ ENGINEERING PRINCIPLES

Built around evidence, not guesswork.

The public website is deliberately lightweight. The full Python agent, FastAPI service, Streamlit UI, regression tests and n8n workflows remain available in the same GitHub repository for deeper review.

01 /

Evidence first

Request IDs, response codes, service status and missing context are surfaced before root-cause assumptions.

02 /

Deterministic controls

Severity and high-risk routing are controlled by application rules, not unconstrained model output.

03 /

Human approval

Outage, security and failed-tool scenarios stop at a clearly marked approval boundary.

04 /

Verifiable implementation

Both the browser demo engine and original Python code are version-controlled and tested.

Browser simulation ≠ Python backendThe website runs local deterministic JavaScript. Original Python/FastAPI, agent tooling, optional LLM code, tests and n8n workflows remain reviewable in GitHub but are not executed here.
