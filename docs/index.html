What this project demonstrates

01 · Investigation

Evidence before conclusions

Identify missing request IDs, timestamps, environment details, reproduction steps and source limitations before asserting a cause.

02 · Communication

Separate audiences

Produce a useful customer update and a distinct engineering handoff with reproduction status, impact, evidence and next checks.

03 · Risk & escalation

Human approval boundary

Deterministic guards escalate high-severity issues and missing diagnostic evidence instead of granting an agent unrestricted authority.

04 · Implementation

Inspect the actual code

The repository contains Python workflow logic, FastAPI endpoints, optional credential-gated LLM tool calling, tests, and n8n orchestration examples.
